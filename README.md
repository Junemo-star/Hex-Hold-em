# 🎴 Hex & Hold'em — บ่อนพนันเวทมนตร์

**Hex & Hold'em** เป็นเกมเว็บแนว **Poker Roguelike Synergistic Score-Attack** ในธีมบ่อนพนันแฟนตาซีลึกลับ ที่ผู้เล่นต้องจัดชุดไพ่โป๊กเกอร์ควบคู่กับการเรียงคอมโบ **เครื่องรางเวทมนตร์ (Charms)** เพื่อทำแต้ม `Chips × Mult` ให้ทะลุเป้าหมายของโต๊ะพนันทั้ง 8 ชั้น และโค่นเจ้ามือพ่อมดประจำชั้นให้สำเร็จ

---

## 💡 แรงบันดาลใจ (Inspiration)

โปรเจกต์นี้ได้รับแรงบันดาลใจหลักมาจากเกม **[Balatro](https://www.playbalatro.com/)** โดยนำหัวใจสำคัญความสนุกของ Balatro มาประยุกต์ใช้ ได้แก่:
- **สูตรคำนวณแต้ม `Chips × Mult`** ที่คำนวณทีละจังหวะจากซ้ายไปขวา พร้อมเสียงสังเคราะห์ไล่ระดับเสียง (Rising Pitch) และตัวเลขเด้งทีละขั้น
- **การจัดลำดับความสามารถ (Order Matters):** การวางเครื่องรางแบบ `+Mult` ไว้ทางซ้ายสุด ก่อนเครื่องรางแบบ `×Mult` ทางขวาสุด จะทำให้ผลคูณทวีคูณขึ้นอย่างมหาศาล
- **เอกลักษณ์เฉพาะของ Hex & Hold'em:** โฟกัสที่การสะสมและจัดเรียง **เครื่องรางเวทมนตร์ (Charms)** ล้วนๆ และเพิ่มระบบ **เจ้ามือบอสพ่อมด 8 ชั้น** ที่มีบุคลิก บทพูดโต้ตอบสดบนโต๊ะ และ **คำสาปที่เปลี่ยนกติกาการเล่นกลางคัน**

### 🎨 การใส่รูปภาพเอง (Custom Art Slots)
ตัวเกมมีคอมโพเนนต์ `<ArtSlot>` ที่ตรวจสอบไฟล์รูปภาพอัตโนมัติ หากต้องการเปลี่ยนจาก Emoji เป็นภาพวาดหรือ Pixel Art ของตัวเอง เพียงนำไฟล์ `.png` ไปวางไว้ที่:
- รูปเครื่องราง: `public/art/charms/<id>.png` (เช่น `public/art/charms/beer-jug.png`)
- รูปเจ้ามือบอส: `public/art/dealers/<id>.png` (เช่น `public/art/dealers/madame-moth.png`)

หากไม่มีไฟล์ภาพในโฟลเดอร์ เกมจะแสดง Emoji และกรอบ CSS แทนโดยอัตโนมัติ

## 🧙‍♂️ รายชื่อเจ้ามือบอสทั้ง 8 ชั้น (Boss Dealers)

ในแต่ละชั้น ผู้เล่นต้องผ่าน **โต๊ะเล็ก (Small)** → **โต๊ะใหญ่ (Big)** → **เจ้ามือบอส (Boss)** โดยเจ้ามือแต่ละชั้นมีคำสาปเฉพาะตัวดังนี้:

| ชั้น | เจ้ามือ | ฉายา | คำสาปประจำโต๊ะ |
| :---: | :--- | :--- | :--- |
| **1** | 🦋 **มาดามโมธ** (`madame-moth`) | แม่มดแมลงเม่า | **ผงปีกมอดไหม้:** หลังเล่นครบ 2 มือ ไพ่ ♥ ทั้งหมดจะไม่ถูกนับแต้ม |
| **2** | 🧛 **บารอนกริมสัน** (`baron-crimson`) | ขุนนางแวมไพร์ | **ภาษีโลหิต:** ทุกครั้งที่กด Discard จะถูกสูบเงิน `-$1` |
| **3** | 🌫️ **สามพี่น้องหมอก** (`mist-sisters`) | ภูตหมอกลวงตา | **หมอกบังตา:** หลังเล่นมือแรก ทุกตาจะมีไพ่ในมือ 1 ใบถูกพลิกคว่ำมองไม่เห็นหน้าไพ่ |
| **4** | 🗿 **ท่านโกเลมเหล็ก** (`iron-golem`) | ผู้คุมกฎศิลาเหล็ก | **ตรวนเหล็กถ่วงมือ:** ขนาดมือลดลง 1 ใบตลอดทั้งโต๊ะ (จั่วขึ้นมือได้สูงสุด 7 ใบ) |
| **5** | 🎩 **จอมกลวิกเตอร์** (`victor-illusionist`) | นักมายากลลวงโลก | **สลับกลลวงตา:** หลังเล่นทุกมือ ตำแหน่งเครื่องรางทั้งหมดจะถูกสลับแบบสุ่ม |
| **6** | 🔮 **หมอดูเซเลน** (`selene-oracle`) | พยากรณ์แห่งดวงดาว | **คำพยากรณ์ต้องห้าม:** ห้ามเล่นมือ `Pair` หากฝืนเล่นจะได้ 0 แต้มทันที |
| **7** | 💀 **ราชาโครงกระดูก** (`skeleton-king`) | กษัตริย์ผู้วายชนม์ | **ตราผนึกราชันย์:** หลังเล่นครบ 2 มือ เครื่องรางช่องซ้ายสุดจะถูกปิดผนึก ไม่แสดงผล |
| **8** | 👁️ **เดอะเฮาส์** (`the-house`) | จอมเวทเจ้าของบ่อน | **กฎเหล็กของเจ้ามือ:** ห้ามเล่นชนิดมือโป๊กเกอร์ซ้ำกับที่เคยเล่นในโต๊ะนี้ และเมื่อทำแต้มถึงเป้าครั้งแรกจะเข้าสู่ **Phase 2** (เป้าหมายเพิ่มอีก +50% พร้อมได้รับ +2 Hands) |
